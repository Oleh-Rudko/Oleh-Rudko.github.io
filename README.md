## Deploy (GitHub Pages)

1. Create a public repo `<username>.github.io`.
2. Push `index.html` to `main`.
3. Settings → Pages → Branch: `main` / `(root)` → Save.
4. Site goes live at `https://<username>.github.io` within ~1 minute.
